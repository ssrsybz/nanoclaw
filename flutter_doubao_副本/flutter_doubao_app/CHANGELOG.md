# 更新日志

## [1.1.0] - 2026-02-21

### 新增功能
- **语音通话视频头像**: 在语音通话界面添加循环播放的视频头像，营造真人聊天的沉浸感
  - 视频文件位于 `assets/videos/avatar.mp4`
  - 支持视频循环播放
  - 圆形裁剪显示，配合边框和阴影效果

- **视频通话功能**: 集成火山引擎 RTC SDK 实现视频通话
  - 支持前后摄像头切换
  - 支持麦克风和扬声器控制
  - 支持本地和远程视频渲染

### 优化改进
- **TTS 字幕显示优化**: 重新设计字幕显示区域
  - 支持多行文本自动换行
  - 添加图标标识（麦克风/机器人）
  - 优化字幕容器样式（圆角边框、半透明背景）

- **语音通话界面优化**: 
  - 使用 `SingleChildScrollView` 支持长文本滚动
  - 优化整体布局和视觉效果

### 问题修复
- **修复挂断黑屏问题**: 移除重复的 `Navigator.pop` 调用，确保挂断后正确返回聊天界面
- **修复视频循环播放问题**: 添加视频播放监听器，确保视频循环播放

### 依赖更新
- 添加 `video_player: ^2.8.1` 用于视频播放
- 添加 `volc_engine_rtc: ^3.58.1` 用于视频通话
